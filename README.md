# ক্রিপ্টো ক্যান্ডেল প্রেডিক্টর

Binance বা Yahoo Finance থেকে ক্রিপ্টোর আগের ক্যান্ডেল ডেটা এনে পরের ক্যান্ডেলের পূর্বাভাস দেয়:

| আউটপুট | মানে |
|---|---|
| **দিক** | পরের N টি ক্যান্ডেলে দাম ▲ উপরে না ▼ নিচে যাবে, সম্ভাবনা (%) সহ |
| **আনুমানিক দাম** | পরের ক্লোজ কত হতে পারে, সাথে ৮০% সম্ভাব্য রেঞ্জ |
| **সিগন্যাল** | BUY / SELL / HOLD |
| **ব্যাকটেস্ট** | একই নিয়মে অতীতে চালালে কতবার সঠিক হতো, লাভ-ক্ষতি কত হতো |

দুইভাবে চালানো যায়: **Python স্ক্রিপ্ট** (`predict.py`) আর **ওয়েব ড্যাশবোর্ড** (`dashboard.py`)।

সার্ভারে হোস্ট করতে চাইলে **[DEPLOY.md](DEPLOY.md)** দেখুন। সেখানে Docker, এক কমান্ডে VPS সেটআপ, ডোমেইন + HTTPS আর পাসওয়ার্ড সুরক্ষার ধাপ আছে।

---

## ১. ইনস্টল

Python 3.10 বা নতুন সংস্করণ লাগবে।

```bash
cd crypto_predictor
pip install -r requirements.txt
```

---

## ২. ওয়েব ড্যাশবোর্ড

```bash
streamlit run dashboard.py
```

ব্রাউজারে http://localhost:8501 খুলবে। বাম পাশে সেটিংস দিন: উৎস, সিম্বল, টাইমফ্রেম, ক্যান্ডেল সংখ্যা, মডেল, থ্রেশহোল্ড। তারপর **▶ বিশ্লেষণ চালান** চাপুন।

ড্যাশবোর্ডে যা থাকে:
- **উপরের কার্ডগুলো:** বর্তমান দাম, সিগন্যাল, উপরে যাওয়ার সম্ভাবনা, আনুমানিক দাম, ব্যাকটেস্টের নির্ভুলতা
- **📊 চার্ট:** ক্যান্ডেলস্টিক, EMA 21/50, Bollinger Band, প্যাটার্ন মার্কার, ভলিউম, RSI, আর পূর্বাভাসের বিন্দু ও রেঞ্জ
- **🧪 ব্যাকটেস্ট:** নির্ভুলতা, p-value, স্ট্র্যাটেজি বনাম Buy & Hold রিটার্ন, ড্রডাউন, প্রতিটি পূর্বাভাসের তালিকা (CSV ডাউনলোড)
- **🕯️ প্যাটার্ন:** এই কয়েনের ডেটায় প্রতিটি ক্যান্ডেল প্যাটার্নের পর আসলে কতবার দাম উপরে গেছে
- **🔍 ফিচারের গুরুত্ব:** মডেল কোন তথ্যের উপর সবচেয়ে বেশি নির্ভর করছে
- **📄 ডেটা:** কাঁচা ডেটা ও ইন্ডিকেটর (CSV ডাউনলোড)

নিজের CSV ফাইলও আপলোড করা যায়। দরকারি কলাম: `time, open, high, low, close, volume`।

## ৩. কমান্ড লাইন স্ক্রিপ্ট

```bash
# BTC, ১ ঘণ্টার ক্যান্ডেল, Binance থেকে
python predict.py --symbol BTCUSDT --interval 1h

# ETH, ৪ ঘণ্টা, Yahoo Finance থেকে, ৩টি ক্যান্ডেল পরের পূর্বাভাস
python predict.py --source yahoo --symbol ETH-USD --interval 4h --horizon 3

# প্রতিটি নতুন ১৫ মিনিটের ক্যান্ডেল বন্ধ হলে নিজে থেকে আবার পূর্বাভাস দেবে
python predict.py --symbol SOLUSDT --interval 15m --watch

# অন্য প্রোগ্রামে ব্যবহারের জন্য JSON আউটপুট
python predict.py --symbol BTCUSDT --interval 1d --json
```

### সব অপশন

| অপশন | ডিফল্ট | কাজ |
|---|---|---|
| `--source` | `binance` | `binance` অথবা `yahoo` |
| `--symbol` | `BTCUSDT` | `BTCUSDT`, `BTC/USDT`, `BTC-USD` যেকোনো ফরম্যাট চলবে |
| `--csv` | – | Binance/Yahoo-র বদলে নিজের CSV ফাইল |
| `--interval` | `1h` | `1m 3m 5m 15m 30m 1h 2h 4h 6h 8h 12h 1d 3d 1w 1M` |
| `--limit` | `1000` | কয়টি ক্যান্ডেল আনবে (বেশি হলে ভালো, তবে ধীর) |
| `--horizon` | `1` | কয়টি ক্যান্ডেল পরের পূর্বাভাস |
| `--model` | `gb` | `gb` (Gradient Boosting), `rf` (Random Forest), `linear` |
| `--threshold` | `0.55` | সম্ভাবনা ≥ ৫৫% হলে BUY, ≤ ৪৫% হলে SELL, মাঝে HOLD |
| `--no-backtest` | – | ব্যাকটেস্ট বাদ দিয়ে দ্রুত শুধু পূর্বাভাস |
| `--min-train` | `300` | ব্যাকটেস্টে প্রথম ট্রেনিংয়ে কয়টি ক্যান্ডেল |
| `--retrain-every` | `50` | ব্যাকটেস্টে কত ক্যান্ডেল পর পর মডেল নতুন করে ট্রেন হবে |
| `--fee` | `0.1` | প্রতি ট্রেডে ফি (%) |
| `--allow-short` | – | SELL সিগন্যালে শর্ট পজিশন ধরবে (না দিলে শুধু বিক্রি করে বের হবে) |
| `--json` | – | JSON আউটপুট |
| `--save-csv FILE` | – | আনা ডেটা সেভ করবে |
| `--save-predictions FILE` | – | ব্যাকটেস্টের প্রতিটি পূর্বাভাস সেভ করবে |
| `--watch` | – | প্রতিটি নতুন ক্যান্ডেলে আবার চালাবে (Ctrl+C দিয়ে বন্ধ) |

## ৪. ভেতরে কীভাবে কাজ করে

1. **ডেটা:** শুধু সম্পূর্ণ (বন্ধ হওয়া) ক্যান্ডেল নেওয়া হয়। এখনো চলমান ক্যান্ডেল বাদ যায়।
   - **Binance:** API key লাগে না। ১০০০-এর বেশি ক্যান্ডেল পেজ করে আনা হয়। `api.binance.com` ব্লক থাকলে `data-api.binance.vision` থেকে আনে।
   - **Yahoo:** যে টাইমফ্রেম Yahoo-তে নেই (যেমন 4h), সেটা 1h ক্যান্ডেল জোড়া দিয়ে বানানো হয়।
2. **ফিচার (৫০টির বেশি):**
   - আগের রিটার্ন
   - অস্থিরতা
   - ক্যান্ডেলের গঠন (বডি, উপরের-নিচের শ্যাডো)
   - RSI, MACD, EMA, Bollinger Band, ATR, Stochastic, ভলিউম, OBV
   - ১৭টি ক্যান্ডেলস্টিক প্যাটার্ন: Doji, Hammer, Engulfing, Harami, Morning/Evening Star, Three White Soldiers ইত্যাদি
3. **দুটি মডেল:**
   - একটি ক্লাসিফায়ার দিক অনুমান করে (সম্ভাবনা সহ)
   - একটি রিগ্রেসর রিটার্ন অনুমান করে, তা থেকে দাম বের হয়
   - দুটি একমত না হলে রিপোর্টে "সিগন্যাল দুর্বল" লেখা থাকে
4. **Walk-forward ব্যাকটেস্ট:**
   - প্রতিটি পূর্বাভাসের সময় মডেল শুধু তার আগের ডেটা দেখে, ঠিক বাস্তবের মতো।
   - নির্ভুলতাকে একটা **বেসলাইনের** সাথে তুলনা করা হয়: সবসময় বেশি-হওয়া দিকটা অনুমান করলে যত শতাংশ সঠিক হতো।
   - **p-value** দিয়ে দেখা হয় ফলাফল শুধু ভাগ্যের কারণে কিনা।

## ৫. ফলাফল কীভাবে বুঝবেন (জরুরি)

- ক্রিপ্টোর দাম মূলত এলোমেলো। তাই শুধু ক্যান্ডেল দেখে করা পূর্বাভাস সাধারণত **৫০–৫৫%** সঠিক হয়।
- ব্যাকটেস্টে নির্ভুলতা বেসলাইনের চেয়ে বেশি না হলে, বা p-value ০.০৫-এর বেশি হলে, ওই সেটিংসের সিগন্যালের উপর ভরসা করবেন না। রিপোর্ট আর ড্যাশবোর্ড নিজেই এটা লিখে জানায়।
- অনেক রকম সেটিংস চেষ্টা করে সবচেয়ে ভালোটা বেছে নিলে সেটাও overfitting। আসল টাকা লাগানোর আগে কয়েক সপ্তাহ `--watch` দিয়ে কাগজে-কলমে (paper trading) মিলিয়ে দেখুন।
- **এটি বিনিয়োগ পরামর্শ নয়।** যতটুকু হারাতে পারবেন তার বেশি বিনিয়োগ করবেন না।

## ৬. সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| `Binance-এ সংযোগ করা যায়নি` | ইন্টারনেট দেখুন। কিছু দেশে Binance ব্লক থাকে, তখন `--source yahoo` ব্যবহার করুন |
| `Invalid symbol` | Binance-এ সিম্বলটি আছে কিনা দেখুন (যেমন `BTCUSDT`, `ETHUSDT`) |
| Yahoo-তে কম ক্যান্ডেল আসছে | Yahoo-র সীমা: 1m ডেটা ৭ দিন, 5m–30m ডেটা ৬০ দিন, 1h ডেটা ~২ বছর পর্যন্ত। বেশি ডেটার জন্য Binance ব্যবহার করুন |
| `ডেটা খুব কম` | `--limit` বাড়ান (অন্তত ৫০০) |
| Yahoo `Too Many Requests` | কিছুক্ষণ অপেক্ষা করে আবার চালান |

### টেস্ট চালানো

প্রথমবার টেস্টের প্যাকেজ ইনস্টল করুন:
```bash
pip install -r requirements-dev.txt
```
তারপর টেস্ট চালান:
```bash
python -m pytest tests -q
```

টেস্টগুলো যা যাচাই করে:
- কোনো ফিচার ভবিষ্যতের ডেটা দেখছে না
- এলোমেলো দামের উপর মডেল ভান করে ভালো ফল দেখাচ্ছে না
- Binance/Yahoo-র ডেটা ঠিকমতো পার্স হচ্ছে (নেটওয়ার্ক ছাড়াই)
